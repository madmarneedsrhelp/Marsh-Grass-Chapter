# Marsh-Grass-Chapter
Code & Files necessary to redo marsh grass chapter analyses!
- Pipeline code: goes through cleanup process of the ASV files (phyloseq) using DADA2 bioinformatic pipeline for both MGPT1 (2023) & MGPT2 (2025) data
- MG_GitHub.Rmd: goes through statistical tests and analyses of microbial data derived from the ASV files and the metadata collected.
- Statistical results include: beta dispersion and beta/alpha diversity anlyses, differential abundance code (structural zeros) and analyses of most relative abundant taxa, visualization via stacked barplots ~ and environmental data statistics (PAM & nutrient correlations).
- Any dataframes needed to complete this analyses have been cleaned up and included
- Should be able to rerun stats start to finish ~ and make plots ~ based on provided code and supporting files
- This is for a community composition study on microbial mat & spartina systems in intertidal areas of the mid-atlantic coast ~ samples were collected from in-field transects set up in June, July & Dec 2023 and July 2025~ focus is on composition shifts and proximity to marsh grass tufts, analzying the potential for microbial and nutrient handoffs ~ this will be a chapter of my dissertation once completed and published.
